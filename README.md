# Ray Peratta

AI automation engineer based in Lisbon. I build systems that take repetitive work off people's plates: n8n and Make workflows, AI agents, and RAG chatbots that answer from your own documents.

Before going independent I spent over two years in consulting (Accenture, Conectys) automating reporting and data workflows for multinational clients, so messy processes and legacy systems are familiar territory.

## What I build

**Workflow automation** with n8n and Make: lead capture and enrichment, CRM sync, document processing, notifications.

**AI agents and RAG chatbots**: assistants that answer questions from PDFs, manuals and internal wikis, with citations instead of guesses.

**Custom integrations** in Python and TypeScript when no-code falls short: FastAPI backends, vector databases, LangChain and LangGraph agents.

## Featured projects

- [rag-document-qa](https://github.com/rayperatta/rag-document-qa): production-ready RAG system for PDF Q&A. LangChain, ChromaDB, FastAPI, Docker.
- [ai-job-hunter](https://github.com/rayperatta/ai-job-hunter): multi-agent LangGraph system that scrapes job postings, analyzes fit, and tailors CVs and cover letters.
- [n8n-lead-enrichment](https://github.com/rayperatta/n8n-lead-enrichment): n8n workflow that scores inbound leads with an LLM and routes each one by score.
- [ai-document-intake](https://github.com/rayperatta/ai-document-intake): LLM-powered extraction from emails, PDFs and invoices into Postgres, with validation and automatic routing.
- [dailyops-bot](https://github.com/rayperatta/dailyops-bot): .NET 8 reporting bot. Ingests operational data, detects anomalies, generates Excel/PDF reports on a daily schedule.
